# Changelog

## 0.1.1

- Published through the npm Trusted Publisher (GitHub Actions provenance). No functional changes.
- Build cache files are no longer included in the package.

## 0.1.0

First release.

- **Printful** node: Catalog, Country, File, Mockup, Order, Platform Product, Platform Variant, Product, Product Template, Product Variant, Shipping, Store, Warehouse Product and Webhook resources (47 operations), usable as an AI-agent tool.
- **Printful Trigger** node: order, package, product and stock events through the store webhook.
- **Printful API** credential: private token with optional store ID for account-level tokens.
